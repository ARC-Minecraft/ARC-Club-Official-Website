板块一 · 我的世界基岩生态开发

现役 · 面向 EndStone 基岩服 / AstrBot / Bedrock Addon · 开源在 github.com/ARC-Minecraft

🧩

本组织 ARC-Minecraft / 弧光技术部（基岩生态）

本组织 github.com/ARC-Minecraft 是弧光技术部负责基岩生态的小组，专注 EndStone 基岩服（Python 插件生态）与 Bedrock Addon 内容工具（自动汉化器、世界区块重置等）。
技术部同时维护 我的世界基岩服务器 5 端口运行所依赖的整套核心（银行、监狱、商店、成就、PvP、AI Agent、QQ 群服互通等）。所有插件在弧光服务器 arcclub.top 上实战验证后再开源发布。

技术栈与能力

🐍

Python 全栈

所有 EndStone 插件均使用 Python 开发，配合 asyncio 提供高并发能力；AstrBot 消息中枢、Addon 工具、运维脚本同语言体系。

🔌

EndStone 插件生态

基于 EndStone（Bedrock 服务端 C++/Python 核心），自研经济、PvP、AI、跨服、AstrBot 互通等 19+ 插件。

🤖

AI Agent / 工具调用

基于 OpenAI 的可操作本服 AI 助手（ARC-AI-Helper / ARC-AI-Builder），触发词对话、工具调用、银行业务 / 监狱 / 领地 / 天眼 / 自动建造。

🛰️

AstrBot 消息中枢

AstrBot 群服互通 WebSocket Hub，跨服、跨设备、QQ ↔ Minecraft 双向消息；与 QQ-Sync-Plugin 配套使用。

🗺️

Bedrock Addon 工具链

Addon 自动汉化器（ARC-MCBE-Addon-Auto-Localizer）、Amulet 世界区块重置工具，专注 MCBE 内容本地化与运维。

🛡️

MIT / AGPL 开源

绝大多数插件采用 MIT 协议，鼓励二次开发；Amulet 区块重置工具基于 AGPL-3.0，符合社区约定。

板块二 · WoTB 社区开发（历史）

2015–2018 · 弧光起源项目 · 战绩查询 / 车辆名人堂 / QQ 战绩查询插件 · 多数已停止维护，源码与设计沉淀在技术部

📜

弧光起家的那几年

弧光游戏俱乐部最早（2015）就是 WoTB（坦克世界闪电战）的 -SDT- 军团，更名 -ARC- 后，技术部的前身是 WoTB 社区开发组，从战绩查询、车辆名人堂伤害记录，到 QQ 战绩查询插件 / ARC App 移动端，为 WoTB 社区做了一整代工具链。2018 转向基岩服后大部分老项目停止维护，但代码与产品思路沉淀下来，构成今天基岩生态的雏形。

历史项目

📱

ARC App（移动端）

状态：已停止维护
弧光初代移动端 App，主打战绩查询与车辆名人堂伤害记录，是当时 WoTB 中文圈少数能离线查玩家 / 车辆 / 战绩的第三方 App。iOS / Android 双端，长期霸榜中文区 WoTB 工具类目。

🏆

车辆名人堂

状态：数据归档保留
收录全车辆最大伤害 / 平均伤害 / 通杀次数 / 装甲穿透率等数据，按版本、按车辆排行。数据被无数 WoTB 中文玩家引用，停止更新后作为历史档案保留。

🔌

QQ 战绩查询插件（v1.0.0）

状态：已停止维护
基于 CoolQ / 早期机器人框架的 QQ bot 插件，在 QQ 群内直接查询玩家战绩。1.0.0 版本后受机器人平台打击影响停更，下面是当时的演示视频。
